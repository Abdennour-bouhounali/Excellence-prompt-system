Étape 0 • Activation des prérequis

Ce que tu dois déjà savoir

Avant de simplifier des racines carrées, vérifions que tu maîtrises les bases. Réponds à ces trois questions diagnostiques pour démarrer.

🔍 Question 1 / 3 — Carrés parfaits

Lequel de ces nombres est un carré parfait ?

✅ Parfait ! $49 = 7^2$ est bien un carré parfait. Sa racine carrée est $\sqrt{49} = 7$.
❌ Pas tout à fait. Un carré parfait est le carré d'un entier. $49 = 7^2$, donc $49$ est le carré parfait ici.
🔍 Question 2 / 3 — Propriété fondamentale

Quelle propriété est toujours vraie pour $a \geq 0$ et $b \geq 0$ ?

✅ Excellent ! $\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}$ est la propriété clé de toute la leçon.
❌ Attention ! Seule la propriété du produit fonctionne : $\sqrt{a \times b} = \sqrt{a} \times \sqrt{b}$. La somme et la différence ne se distribuent PAS.
🔍 Question 3 / 3 — Racine d'un carré

Combien vaut $\sqrt{a^2}$ pour tout réel $a \geq 0$ ?

✅ Bravo ! $\sqrt{a^2} = a$ (pour $a \geq 0$). C'est exactement ce principe qu'on applique pour "extraire" un carré parfait de sous la racine.
❌ La racine carrée et le carré sont des opérations inverses : $\sqrt{a^2} = a$. Exemple : $\sqrt{9} = \sqrt{3^2} = 3$.

🤔 Prédis : Quel coefficient entier sort devant $\sqrt{\text{reste}}$ ?

💡 Ce que tu viens d'observer

En décomposant $n = k^2 \times r$, on peut écrire : $\sqrt{n} = \sqrt{k^2 \times r} = k\sqrt{r}$. Le carré parfait sort de la racine sous forme de sa racine carrée !

2
Étape 2 • Intuition & Formalisation

La règle formelle

⚡
« Extraire un carré parfait, c'est trouver le plus grand carré parfait qui divise le nombre sous la racine — et le faire sortir. »
$$\sqrt{k^2 \times r} = k\sqrt{r} \quad \text{avec } r \text{ sans carré parfait diviseur}$$

📋 Les carrés parfaits à mémoriser

$n$123456789101112
$n^2$149162536496481100121144
⚠️ Règle d'or : toujours le PLUS GRAND carré parfait !

Pour $\sqrt{72}$ : $72 = 4 \times 18$ donne $2\sqrt{18}$ — incomplet car $18 = 9 \times 2$ contient encore un carré !
Il faut $72 = 36 \times 2$ (36 est le plus grand), donc $\sqrt{72} = 6\sqrt{2}$.

⬟ Méthode en 3 étapes

  1. Trouver le plus grand carré parfait $k^2$ qui divise $n$.
  2. Décomposer $n = k^2 \times r$ où $r = n \div k^2$.
  3. Appliquer : $\sqrt{n} = \sqrt{k^2 \times r} = k\sqrt{r}$.

Étape 3 • Entraînement guidé

Exemples travaillés pas à pas

Exemple 1 : Simplifier $\sqrt{50}$

  1. Plus grand carré parfait diviseur de $50$ : $25$ (car $50 \div 25 = 2$). ✓
  2. Décomposer : $50 = 25 \times 2$
  3. Appliquer : $\sqrt{50} = \sqrt{25 \times 2} = 5\sqrt{2}$

Exemple 2 : Simplifier $\sqrt{98}$

  1. Tester : $98 \div 4 = 24{,}5$ ✗ ; $98 \div 49 = 2$ ✓ → Plus grand carré parfait : $49$.
  2. Décomposer : $98 = 49 \times 2$
  3. Appliquer : $\sqrt{98} = \sqrt{49 \times 2} = 7\sqrt{2}$

Exemple 3 : Simplifier $3\sqrt{48}$

  1. Plus grand carré parfait diviseur de $48$ : $48 \div 16 = 3$ ✓ → $16$.
  2. $\sqrt{48} = \sqrt{16 \times 3} = 4\sqrt{3}$
  3. $3\sqrt{48} = 3 \times 4\sqrt{3} = 12\sqrt{3}$

Étape 4 • Réparation des erreurs

Les pièges classiques du Brevet

Ces erreurs apparaissent dans des centaines de copies du Brevet chaque année. Identifie-les pour ne plus jamais les commettre.

⛔ Piège 1 — La racine d'une somme
❌ FAUX : $\sqrt{9 + 16} = \sqrt{9} + \sqrt{16} = 3 + 4 = 7$
✅ VRAI : $\sqrt{9 + 16} = \sqrt{25} = 5$   (car $\sqrt{a+b} \neq \sqrt{a}+\sqrt{b}$)
⛔ Piège 2 — Carré parfait non maximal
❌ INCOMPLET : $\sqrt{72} = \sqrt{4 \times 18} = 2\sqrt{18}$   (18 n'est pas simplifié !)
✅ CORRECT : $\sqrt{72} = \sqrt{36 \times 2} = 6\sqrt{2}$   (36 est le PLUS GRAND carré parfait)
⛔ Piège 3 — Oublier le coefficient extérieur
❌ FAUX : $3\sqrt{28} = 3\sqrt{4 \times 7} = 3\sqrt{7}$   (oubli du facteur 2 !)
✅ VRAI : $3\sqrt{28} = 3 \times 2\sqrt{7} = 6\sqrt{7}$
⛔ Piège 4 — Signe de la racine
❌ FAUX : $\sqrt{(-5)^2} = -5$   (la racine est toujours ≥ 0 !)
✅ VRAI : $\sqrt{(-5)^2} = \sqrt{25} = 5 = |{-5}|$
🎯 Test de détection d'erreur

Parmi ces simplifications, laquelle est correcte ?

✅ Exact ! $\sqrt{45} = \sqrt{9 \times 5} = 3\sqrt{5}$ — seule simplification correcte ici.

📖 Explication modèle pour $\sqrt{200}$

Étape 1 : Je cherche le plus grand carré parfait qui divise 200. $200 \div 100 = 2$ ✓ → Le plus grand est 100.

Étape 2 : Je décompose : $200 = 100 \times 2$.

Étape 3 : J'applique : $\sqrt{200} = \sqrt{100 \times 2} = \sqrt{100} \times \sqrt{2} = 10\sqrt{2}$.
